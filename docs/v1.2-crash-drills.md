# v1.2 Crash Drills（V12-013A / V12-013B）

**状态：** 演练账本模板 + 可自动化子集已落地；真实 OS 强杀需在目标机补跑并勾选。

## V12-013A — Worker / Runtime

| 演练 | 期望 | 证据类型 | 自动化 |
|---|---|---|---|
| worker 首 heartbeat 前死亡 | 保持 `starting` → reconcile/`manual_required`，不短暂 `running` | DB state 轨迹 | lifecycle finalize 路径 |
| 运行中强杀 worker | `lost` → reconcile；不重放 prompt | DB + PID | reconcile 单测 |
| Server 端口被未知进程占用 | `runtime start` 拒绝，不 kill | registry error kind | service 冲突路径 |
| active run 时 runtime stop | 拒绝（除非 `--force`） | ValidationError | `test_runtime_service` |
| prompt 证据不足 | `manual_required`，不自动重放 | worker `ORCH_PROMPT` 一次性 | worker 协议 |

## V12-013B — Takeover / Cleanup

| 演练 | 期望 | 证据类型 | 自动化 |
|---|---|---|---|
| 并发 takeover | 仅一个进入 `pausing`，另一 `takeover_busy` | DB + error kind | `TakeoverBusyTests` |
| takeover 中 session 不 idle | 不发 human lease，进 `manual_required` | DB last_error | 集成待补 |
| cleanup + active run | `runtime_blocked`，不删 worktree | blockers | `CleanupGuardTests` |
| blocking BeforeWorktreeRemove | prune 失败，目录保留 | hook_blocked | `HookTests` |
| skipped task | 保留，不 prune | task_skipped_retained | cleanup guard |
